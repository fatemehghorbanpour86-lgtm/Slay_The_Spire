# Slay the Spire

## پروژه درس برنامه‌سازی پیشرفته

این پروژه پیاده‌سازی نسخه‌ای از بازی **Slay the Spire** با استفاده از زبان **++C** و فریم‌ورک **Qt** است. هدف پروژه، شبیه‌سازی مکانیک‌های اصلی بازی و طراحی یک نسخه تک‌نفره از این بازی با استفاده از معماری شیءگرا و طراحی ماژولار بوده است.

---

## اعضای تیم

- **فاطمه قربانپور**
- **آناهیتا عامری‌فر**

---

## اطلاعات پروژه

- **دانشگاه:** دانشگاه صنعتی اصفهان
- **استاد:** دکتر علی ایرانی‌دوست
- **درس:** برنامه‌سازی پیشرفته
- **ترم:** ترم ۲

---

## معرفی پروژه

این پروژه شامل پیاده‌سازی نسخه تک‌نفره بازی **Slay the Spire** است که تمامی بخش‌های اصلی بازی از جمله سیستم مبارزه، کارت‌ها، دشمن‌ها، رلیک‌ها، نقشه، کمپ‌فایر، سیستم ذخیره و بارگذاری، سیستم پاداش، صندوقچه‌ها، مینی‌گیم‌ها، رابط کاربری و مدیریت کلی بازی را پوشش می‌دهد.

در توسعه این پروژه تلاش شده است تا علاوه بر پیاده‌سازی مکانیک‌های اصلی بازی، ساختاری ماژولار و قابل توسعه ایجاد شود تا امکان افزودن قابلیت‌های جدید در آینده نیز فراهم باشد.
